# GSGP-Bench 证据等级与记录规范

> 目的：让读者一眼看出“这个数字是什么”，避免把演示值、stub、真实单次运行和论文值混在一起。
> 当前没有 L1/L2 结果；MCP 的“已认证/未认证”是另一条独立的轴。站点上的 L1/L3 单元格多数仍是演示版式。

## 1. 结果等级（六种）

MCP 状态只有 **已认证 / 未认证**，不混入下面的结果等级。

| 状态 | 含义 | 能否作为科学结论 | 当前例子 |
| --- | --- | --- | --- |
| **demo** | 为了展示版式而填的数值 | 否 | 站点大部分结果矩阵 |
| **stub** | 真实接口/流程，但数值引擎是假的 | 否，只能证明工程管线 | IFAM.R + fake HIBLUP dry-run |
| **EXP / exploratory** | 真实计算，但只有一次划分，未审核 | 只能作为探索记录 | GBLUP MCP × GSGP-Sim 500×5k |
| **L1** | 同一数据、划分和指标下完成多重复复现，经维护者复核 | 可以作为本站复现结果 | 暂无 |
| **L2** | 输入模态或协议与论文不同，结果不可直接与 L1 比 | 仅作方法探索 | 暂无 |
| **L3** | 论文报告值，未在本站运行 | 仅作参考，不参与主榜 | 站点占位值尚非真实 L3 |

`demo` 不是证据等级，只是页面状态。`stub` 也不是科学证据。

**MCP 已认证**表示工具包通过中央检测，不自动让任何结果变成 L1；结果仍需独立的证据等级。

## 2. 判定规则

1. **真实计算**：必须由可追溯的代码在固定输入上产生预测；不能用随机数或占位值冒充。
2. **独立评测**：指标必须由 MCP 之外的 runner 用 held-out truth 计算；MCP 不接收 truth。
3. **单次划分不等于 L1**：即便代码、数据和 runner 都是真的，一次 80/20 也只能是 EXP。
4. **L1 需要重复与审核**：固定数据、固定划分协议、多折/多 seed、完整 run manifest、人工复核。
5. **L2 需要说明差异**：输入模态、划分、指标或数据版本与论文不同，不能与 L1 混排。
6. **L3 必须是论文值**：必须能对应到论文表格/图；当前站点的 L3 视觉样式是演示，不是已录入的真实论文值。
7. **公开/私有分离**：公开聚合指标、哈希、划分和 provenance；原始基因型、表型、个体预测不提交、不部署。
8. **升级必须留痕**：从 stub/EXP 升级到 L1 需要新的记录和审核，不是改一个 `status` 字段。

## 3. 当前对象快照

| 对象 | 状态 | 证据/限制 |
| --- | --- | --- |
| IFAM Paper2Skill | `reviewed_with_limitations` | 阅读包真实；补充材料缺失；不是基准结果 |
| IFAM MCP（本地 stdio） | draft / 未认证 | 真实 IFAM.R + fake HIBLUP 流程通过；没有真实 HIBLUP 数值 |
| GBLUP baseline Skill/MCP | **MCP 已认证** | 手动包装；不是 Paper2Agent 生成；中央测试通过；结果仍为 EXP |
| IFAM 真实执行 | 未开始 | HIBLUP v1.1.0 暂不可得 |
| GBLUP MCP × GSGP-Sim 500×5k | **EXP** | 真实 500×5k 基因型 + 模拟性状；经 MCP inspect/fit/export；单次 80/20；Pearson r 0.508 |
| IFAM MCP × GSGP-Sim 500×5k | **STUB** | 真实 IFAM.R 编排 + fake HIBLUP；只展示 Paper2Agent/MCP 管线，数值不可引用 |
| 站点其他 L1/L3 单元格 | demo | 版式占位；不代表真实复现或论文值 |
| L1 / L2 结果 | 暂无 | 需要多重复、审核和 verifier |

## 4. 结果记录要求

公开结果遵循 [`benchmark/schema/result.v1.json`](../benchmark/schema/result.v1.json)，至少包含：

- 论文来源：`algorithm.paper_doi` / `algorithm.paper_title`；
- 数据来源：`dataset.source`、样本量、SNP 数、性状是否模拟；
- 划分：split ID、seed、训练/验证数量、split 哈希；
- 指标：Pearson、R²、bias 斜率、AUC（不适用时 `null`）；
- 证据：`level`、`status`、`certified`、`single_split`、notes；
- 溯源：命令、环境、代码/预测/runner 哈希、输入哈希；
- 公开/私有边界。
