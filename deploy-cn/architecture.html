按网站整理的目录约定

/www/wwwroot/
  gsgp/            ← 本站（index.html 在根）
  SITES.md         ← 站点登记表（名称/端口/根目录/日期）
  <site2>/         ← 未来站，同形状
/etc/nginx/conf.d/
  gsgp.conf        ← 主 server :80（include sites/）
  sites/<name>.conf ← add-site.sh 生成
/opt/
  gsgp-api/server.py
  <site2>-api/server.py   ← 可选
/etc/
  gsgp-bench.env   (600)
  <site2>-bench.env (600)  ← 可选
/etc/systemd/system/
  gsgp-api.service
  <site2>-api.service     ← 可选
新增站三步：SFTP 传内容到 /www/wwwroot/<name>/ → bash add-site.sh <name> [api-port] → 无需新开端口（共用 80）。bench 的 /api/ 为绝对路径，前缀区分站点时天然隔离，无需改前端。
