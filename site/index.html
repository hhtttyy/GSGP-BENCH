把论文里的预测结果，放到你的数据上同条件验真，证据分级、可追溯、数据不出本机，实测汇入公开账本。GSGP-BENCH赋能将论文转化为Skill、MCP，为能力持续沉淀落地。

我们为您服务

面向三类用户，解决同一件事的三个侧面：让基因组预测的数字可信、可比、可讲清。

01

育种与遗传研究者

您的问题

论文数字各说各话：数据集、划分、指标口径都不同，不知道新方法在自己的数据上到底值不值得用。

我们解决

同条件实测参照：GBLUP、IFAM、SBayesRC、BayesR 在公开数据集上按统一协议运行，每个数字带证据等级，缺失如实留空。

场景：为奶牛育种方案挑选基因组预测方法

02

方法开发者

您的问题

新方法缺少公平、可重复的展示位置；自报数字难以被信任，也没有统一的比较入口。

我们解决

论文 → 论文 Skill → 本地 MCP → 独立 runner 的认证链路：提交论文与仓库，经允许清单预审与同条件验证，以证据进入公开账本。

场景：提交 SBayesRC 类新方法进入公开账本

03

审稿人与课堂

您的问题

「论文值 ≠ 实测值」很难向学生或同行讲清；演示值、探索值与复现值经常被混为一谈。

我们解决

证据阶梯与如实标注的账本：探索、复现、跨协议、论文值、流程测试各归其位；AI 解读示范克制的科研表述，仅供参考。

场景：研究生课程上的方法比较案例

为「认真比较」而设计的每个细节。

同条件对比

同一数据集、同一划分、同一指标口径下并排比较 GBLUP、IFAM、SBayesRC、BayesR。缺失与不可比的单元如实留空，而不是补一个好看的数。

数据不出本机

算法与 MCP 工具全部在本地运行。站点只展示公开聚合结果；AI 解读也只接收当前页面上的聚合数字，不接收基因型、表型或样本 ID。

AI 解读 · 仅供参考

由站点配置的模型对当前视图写一段克制的对比解读，明确区分演示、探索与复现，不下没有统计依据的断言。

可追溯记录

每条结果带来源提交、运行环境与内容哈希，任何数字都能回溯到它是如何产生的。

主观估计不混主榜

「待认证」的主观适配度与论文值单独陈列、明确标注，永远不会和实测结果排在同一张榜单里。

开放提交与预审

没有现成的 MCP 文件？提交论文与 GitHub 仓库，平台按允许清单生成「待认证预览」：预期来自人工模板，AI 只写摘要、证据、风险与验证计划，绝不声称已运行。欢迎通过 GitHub Issues 提交你的方法。
