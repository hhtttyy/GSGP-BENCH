生产

我该如何生产

  1. 下载本地套件把 paper2agent/ 放进编码 Agent 的 skills 目录。
  2. 准备论文与代码论文 PDF/链接、代码仓库、输出目录。
  3. 运行提示词生成论文 Skill 与 MCP 工具。
  4. 本地验证用公开或合成数据跑一次，保存日志和产物。
  5. 提交认证GitHub Issue → GSGP-BENCH 团队检测。
  6. 发布通过后标记已认证，进入方法库。

使用

我该如何使用

  1. 选择方法与数据在评测页勾选要比较的方法和数据集。
  2. 先看结果等级演示、复现、探索、流程测试、论文值，含义不同。
  3. 打开运行记录查看 run ID、划分、指标和限制。
  4. 下载 MCP从方法页或 GitHub 仓库获取包和运行说明。
  5. 按 README 运行安装依赖，数据留在本机，网站不执行。

论文 Skill

让 Agent 读懂论文：定位方法、数据、图表、公式和限制，而不是把全文塞进上下文。

MCP 工具

让 Agent 在你的电脑上调用方法。网站不托管、不执行；下载后按 README 运行。

已认证 / 未认证

认证的是 MCP 包，不是结果。已认证表示 GSGP-BENCH 团队实际跑过并核对；未认证可用但风险自担。

MCP 认证与结果等级是什么关系？

MCP 认证回答的是“这个工具包是否被可信地运行”；结果等级回答的是“这次运行结果能引用到什么程度”。两者独立：已认证的 MCP 仍可能只产出演示或探索结果；未认证的 MCP 也可能有真实结果。

需要记住的规则

认证看 MCP 工具，不看结果

已认证：我们实际运行过并核对过输入输出。未认证：可以查看和自行使用，但风险自担。认证不会把探索结果升级成复现。

网站不运行算法

没有在线 MCP，也没有在线 R、HIBLUP 或 GCTB。原始基因型、表型和个人预测留在本地，只公开聚合结果。

AI 只做解释

AI 文本是辅助说明，不是证据、不是排名，也不能替代运行记录。它无法看到原始数据。

常见问题

网站会运行论文代码或 MCP 吗？

不会。所有生成和运行都在你的电脑上完成；网站只展示结果、认证状态和聚合数值。

会接收我的原始数据吗？

不会。原始基因型、表型、样本 ID 和个人预测都不上传；AI 解读也只发送当前页面的聚合数值。

AI 解读可以直接引用吗？

不可以。它只是辅助说明，不是证据、不是排名，也不能替代运行记录或人工审核。

没有统一数据、划分和指标时能排名吗？

不能。跨论文、跨协议的数字不做排名；论文值只作参考，不能和同条件复现混在一起。
