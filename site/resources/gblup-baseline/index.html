GBLUP 基线

自建基线。不是 Paper2Agent 从论文自动生成的 MCP，也不是在线托管的服务。MCP 包已认证；当前证据等级为 探索，不是正式复现。

论文来源

VanRaden, P. M. Efficient methods to compute genomic predictions. Journal of Dairy Science 91:4414–4423 (2008). DOI 10.3168/jds.2007-0980.

数据来源

  • 基因型：上游 IFAM demo 的 500 个体 × 5,000 SNP 本地子集，未提交；
  • 性状：GSGP-Bench 模拟的连续性状，h² = 0.5，200 个因果 SNP，seed 20261019；
  • 划分：一次 80/20，400 训练 / 100 验证；
  • 原始基因型、表型和个体预测只在本地，公开记录只含聚合指标和哈希。

方法

VanRaden 方法构建 GRM；单随机效应 REML 估计方差组分；用训练表型和验证基因型预测验证集遗传值。不能把该实现等同于 IFAM 的多注释随机效应模型。

MCP 工具

  • gblup_inspect_inputs：检查 PLINK、表型、ID 对齐与 split；
  • gblup_fit：拟合 GBLUP/REML，返回验证集预测和 provenance；
  • gblup_export：读取已完成的 run。

MCP 不接收留出的真实值，不计算指标。指标由独立 runner 计算。MCP 是本地 stdio 原型，静态网页不能执行它。

MCP 已认证：GSGP-BENCH 团队已实践验证这个 MCP 包：契约、stdio 初始化/工具列表、inspect/fit/export、直接对照和 schema 检查均通过。认证的是包，不是结果；我们不在线托管，用户自行运行；结果仍为探索。认证记录见仓库 benchmark/algorithms/gblup/certification.json。

本次结果

本次记录由 gblup_inspect_inputs → gblup_fit → gblup_export 的真实 stdio 调用产生；直接对照的科学指标与 MCP 结果一致。

  • Pearson r: 0.5075
  • R²: 0.2576
  • prediction bias slope: 1.2117
  • 证据：探索，单次划分；结果未认证，不是 正式复现

局限

  • 手写基线，不证明 Paper2Agent 的生成能力；
  • 单随机效应，不支持 IFAM 多注释随机效应；
  • 模拟性状，不是 IFAM 论文的 Duroc 表型；
  • 单次划分，不能升级为 正式复现；
  • MCP 已认证，但不在线托管；网页只展示说明和证据。
