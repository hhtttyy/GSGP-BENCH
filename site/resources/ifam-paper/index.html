Scope & boundaries

Useful for

  • 让 Agent 定位方法、数据、图表、公式和限制，而不是把整篇论文塞进上下文。
  • 回答“IFAM 需要什么输入”“10× 合并规则是什么”“各数据集如何划分与评估”。
  • 把论文中的设置与本站 benchmark 记录区分开；论文值只作为 L3 参考。
  • 在阅读基础上起草方法护照、实验设计和审稿问题，并附上可核对的章节。

Not evidence for

  • 不是 IFAM 的复现结果，也不能证明 IFAM 在任何新数据上更好。
  • 不包含 Duroc、UKB、WTCCC 或其他个体级数据，不包含上游代码。
  • 不包含补充材料；相关缺失已记录，不能假装已读到。
  • 不是可调用的 MCP 服务，也不是已认证的 benchmark 条目。

在 Agent 中使用

Install & read

Skill 包是为编码 Agent 准备的结构化阅读材料。先读 SKILL.md 了解检索方式，再从 references/index.html 选择章节；不要默认加载整篇论文。

下载的 ZIP 已把全部文件放在顶层 ifam-paper/ 目录内。解压后，将整个目录放进你的 Agent skills 目录，或直接把路径交给 Agent。

原始 Markdown 与图像是权威材料；网页只是阅读渲染。文件哈希见 skill-manifest.json。

Installation sketch

unzip ifam-paper-skill.zip
# → ifam-paper/SKILL.md
#   ifam-paper/references/{index,paper,supplement}.md
#   ifam-paper/assets/figure/*.jpg

# 让 Agent 先读 SKILL.md，再按需检索，例如：
rg -n -i -m 8 'Duroc|randomMax|10-fold' \
  ifam-paper/references/paper.md

具体 skills 目录取决于你的客户端（Claude Code、Codex 等）。本页不假设任何一种安装路径。
